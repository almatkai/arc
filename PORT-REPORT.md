# Arc Rust port report

Arc is rank 13 in Tezbar's source-pinned Store inventory. This portable source targets Tezbar `0.3.0-beta.12` through the schema 3 Rust process contract and protocol 1. It declares `com.tezbar.native.arc`, aliases `raycast.arc`, and retains the 16 original command IDs, modes, preferences, arguments, disabled defaults, menu interval and macOS platform. The original Raycast extension is pinned at commit `3627d9b15ba4506ca8c8ac9d93c4585c5d2ec7ae`. All 57 extension files and the original root MIT license matched their Git blob hashes. See [the source tree](https://github.com/raycast/extensions/tree/3627d9b15ba4506ca8c8ac9d93c4585c5d2ec7ae/extensions/arc/) and [UPSTREAM.json](UPSTREAM.json).

The Browser Company has announced that Arc for desktop will stop working on December 22, 2026. New account creation has already closed. This implementation follows the pinned Arc contract. [Arc Sunset announcement](https://resources.arc.net/hc/en-us/articles/44412972248471-Arc-Sunset-Key-Dates-and-What-to-Expect)

## Command coverage

| Commands | Implementation |
| --- | --- |
| `search-history` | Read-only, bound SQLite queries for Default and sequential Profiles 1–4, stopping at the first absent numbered profile and excluding Arc's system profile. Global date sorting, labels for multiple profiles, and local section errors. |
| `search-downloads` | Default profile downloads with literal path and source search, timestamp, open file, Finder reveal and open source in the default browser. |
| `search-spaces` | Front window's Spaces, active indicator, switch by native ID and copy title. |
| `search-tabs`, `search-space-tabs` | Front window or active Space, Favorites/Pinned/Unpinned sections, retained tab-kind dropdown, fuzzy title/URL/Space and Pinyin matching, native select/reload/close, clipboard, Quick Link and open destinations. |
| `search` | Combined tab, history and suggestion sections with all original sort/visibility preferences. Seven search engines, with online autocomplete for Google, Ecosia and Kagi. Search text only goes to the chosen provider when online suggestions are enabled and the current window is confirmed non-incognito. |
| `new-window`, `new-tab` | Create normal windows and tabs with optional Space selection by name or position. New Tab accepts a comma-delimited list and opens it in order. |
| `new-blank-window`, `new-easel` | Arc's fixed File menu actions through macOS Accessibility. |
| `new-little-arc`, `new-incognito-window` | Explicit URL or search text with stored engine and URL. Little Arc also accepts selected and fallback text. |
| `menu-bar` | Native status item with durable ownership, ten-minute passive refresh, Spaces and Favorites, direct launch of the two search views, settings, explicit refresh and removal. |
| `release-notes`, `boost-gallery` | Open the original Arc release notes and gallery URLs in Arc. |
| `reset-space-tabs` | Explicit confirmation and post-confirmation verification of the Arc process, front window and active Space before invoking Arc's native reset menu item. |

## Boundaries and verification

- Rust owns session state, search and ranking, argument handling, SQLite, typed GPUI list and action payloads, host RPC and the status item's lifecycle. `src/arc.js` is JavaScript for Automation executed by macOS `osascript`. It carries fixed Arc Apple Events and accessibility actions. It receives bounded JSON through stdin and has no shell or eval. Native web suggestions use the fixed system `curl` binary with bounded HTTPS responses, deadlines and cancellation. Node.js is used only by the synthetic scripting test.
- Tab actions carry the Arc process ID and launch timestamp, window ID and tab ID. Reload and close also recheck the captured URL. Browser positions are read to choose a front window or resolve a requested Space number. Effects use native IDs. Reset remains a native active-Space menu action. Its final recheck and macOS menu click are separate calls, so there is a small potential focus-change interval after the check.
- The port treats Arc Favorites and Pinned Tabs as Arc's saved sidebar links. The pinned upstream has no dedicated bookmark command or persisted `StorableSidebar.json` reader. Local data access uses only Arc's declared `User Data` profile paths, `History`, SQLite sidecars and profile display names from `Preferences`. The port has no Arc account login or sync, no Raycast user-store import, and no Tezbar migration paths. Tezbar owns retained host preferences. SQLite may use the existing browser's WAL sharing facilities during live reads.
- The 13 original Raycast AI tool definitions and prompts are preserved in the upstream snapshot. No callable Raycast tool registration is available through this host revision. The native package does not advertise AI tool endpoints.
- GPUI uses bounded section lists and destination pickers. The port does not reproduce remote favicons, nested Raycast action menus, menu shortcut annotations, theme-specific SVG status icons, the exact Fuse.js extended-search operator syntax, or the version-check screenshot. Assets are retained. The status item uses the original raster Arc logo. Tezbar's Quick Link dialog lacks an application binding. The Arc Search with Google shortcut opens the search URL through Arc and does not perform upstream's across-window reuse lookup.
- The pinned minimum Arc version check uses the installed bundle's marketing version. The native Arc dictionary and menu availability, English menu labels, macOS Automation and Accessibility permission prompts, status-item presentation, GPUI keyboard behavior and provider responses still need live acceptance. The vendor's shutdown date may constrain this verification. No real Arc profile, browser, clipboard, app launch or provider request was used in fixtures.
- The source stays portable with zero artifact pins and file entries in `extension.json`. The packager computes target-specific file hashes inside development ZIPs and verifies binary identity, platform architecture, permissions and notices. The Windows build requires fixture mode to execute synthetic commands and rejects normal Windows context for all commands. The Apple Silicon packager requires a binary built without the fixture feature. Local source and Windows evidence ships with adjacent SHA-256 and file inventories. Mac and Windows dependencies are locked to the standalone SDK revision `1a11afc14693cc6463e0b95ae7d61991b4a60427`. See [third-party notices](licenses/THIRD_PARTY.md).
